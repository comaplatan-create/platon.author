# Platon — информационный сайт

Простой статический сайт с большим пиксельным заголовком и описанием преимуществ Platon.

Файлы:
- index.html
- styles.css

Как опубликовать на GitHub Pages (локально в репозитории):

```bash
git add .
git commit -m "Add informational site for Platon"
git push origin main
git checkout -b gh-pages
git push -u origin gh-pages
# Затем можно включить Pages через gh api или в настройках репозитория на GitHub
```
